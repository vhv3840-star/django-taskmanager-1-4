# Жұмыстың нақты скриншоттары

Бұл қалтада №1–4 практикалық жұмыстар үшін PyCharm бағдарламасынан түсірілген 18 PNG бар.
Кадрларда жоба баптаулары, модельдер, маршруттар, миграциялар, ORM нәтижелері,
Admin HTTP формаларын тексеру және 14 тесттің нәтижесі көрсетілген.
15–18 кадрлар жоба құру командаларының журналын және GET, POST, ORM кодын көрсетеді.
